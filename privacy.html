Privacy Policy: Retro Stream Tools

Last updated: November 15, 2026

Retro Stream Tools is a personal app used only by the channel owner, letsgetitretro, on his own computer.

What it accesses

With the channel owner's permission (Google sign-in), it uses the YouTube Data API to read and update his own live broadcast (title, category) and to post messages in his own live chat.

How data is stored

The sign-in token is stored only on the channel owner's own computer. Nothing is stored on any server.

Sharing

No data is sold, shared, or transferred to anyone. No data is used for advertising.

Google API Services

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Through the channel: youtube.com/@letsgetitretro
